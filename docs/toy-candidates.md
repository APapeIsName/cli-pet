# 장난감 팩 후보 (2026-09-30 조사)

생활 속 유행 장난감·물건을 **우리가 직접 그린 캐릭터**로 만드는 0군 시리즈 후보예요. 특정 회사 캐릭터가 아닌 **누구나 만드는 일반 제품군**만 골랐어요.

> 유행 근거는 대부분 언론 기사·플랫폼 발표 수치예요. IP 판단은 조사 수준이고 법률 자문이 아니에요. 출시 전에 이름 상표 검색을 한 번 더 해요.

## 왁뿌볼이란

"**왁**스 **뿌**시기 **볼**". 말랑한 클레이·스퀴시 겉에 녹인 왁스를 입혀 굳힌 손바닥만 한 공이에요. 누르면 왁스 껍질이 "콰사삭" 깨지고 안의 말랑한 점토가 삐져나와요. 깨는 소리와 주무르는 촉감을 같이 주는 ASMR 장난감이에요. 2025년 말 해외 숏폼에서 시작해 2026년 한국에서 크게 유행했어요 (검색량 1월 대비 6월 약 64배, 지그재그 거래액 +500%). 특정 브랜드가 아닌 일반 제품군이에요.

- 참고: 2026-08-31 서울시 조사에서 한 제품에 3세 미만 사용 금지 방부제가 나왔어요. 펫 대사에 실물 사용을 권하는 말("얼려서 부숴 봐")은 넣지 않아요.
