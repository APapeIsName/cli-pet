# 주요 결정 기록

만들면서 정한 것과 그 이유예요. 나중에 방향을 바꿀 때 참고하세요.

## 방향

- **개발자를 위한 펫이지만, 개발 얘기만 하지 않는다.** 작업 상태도 알려 주지만 평소엔 평범한 펫처럼 인사하고, 배고프다 하고, 혼잣말해요.
- **펫은 채팅 내용을 보여주지 않는다.** 보여주는 건 "지금 무슨 일을 하는지"(생각 중, 파일 읽기, 명령 실행, 완료)뿐이에요.

## 캐릭터와 권리

- **기본 팩에는 권리가 확실한 것만 넣는다.** 조사 결과는 `ip-research.md`, 전체 목록은 `packs.csv`에 있어요.
  - 0군 자체 캐릭터(새싹, 둔갑이, 동물 10종, 장난감 5종)는 코드로 그려요. 권리가 100% 우리 것이고, 모든 표정을 공짜로 얻어요. AI 생성 그림은 쓰지 않아요.
  - 1군(열린 라이선스)은 권리자가 공식 배포한 그림을 자르고, 크기를 줄이고, 변환만 해서 넣어요. 표기는 `CREDITS.md`와 팩마다 `LICENSE`에 있어요.
  - 비상업 조건 팩(즌다몬, Unity-chan)은 저장소에 올리지 않았어요. 넣으면 저장소 전체가 비상업 조건에 묶이기 때문이에요.
  - 모코코는 팬킷마다 재배포를 금지해서 넣지 않았어요. Deno 공룡은 로고와 너무 비슷해서 보류했어요.
- **유명 상업 캐릭터는 넣지 않는다.** 포켓몬·산리오·카카오 등은 허락이 없어요. 문의할 곳과 메일 틀은 `inquiry.md`에 있어요. 개인적으로는 커스텀 팩(`~/.cli-pet/packs`)으로만 써요.
- **분류는 두 축**: 내용 축 `category ▸ series`(메뉴에 보이는 것)와 라이선스 축 `group`(0~3군). id는 `분류-시리즈-캐릭터`.

## 기능

- **훅은 상황 키만 보내고, 대사는 펫이 고른다.** 그래야 사용자 대사 파일과 팩 대사로 바꿀 수 있어요. 예전 버전 앱을 위해 기본 문장도 같이 적어요.
- **설정 파일을 고칠 때는 JavaScript로 편집한다.** 원래 순서와 들여쓰기를 지키고, CLIPet이 넣은 항목만 고쳐요. 백업은 처음 한 번만 원본으로 만들어요.
- **Cursor는 따로 연결하지 않는다.** Cursor가 Claude Code 훅을 이미 가져와서, 따로 넣으면 같은 알림이 두 번 가요.
- **그림이 1장뿐인 팩은 추가 팩으로 뺀다.** 메뉴를 단순하게 두고, 원하는 사람만 받아요.
- **소품은 캐릭터 그림에 넣지 않고 아이템으로 만든다.** 캐릭터 그림에는 그 캐릭터 본래의 특징만 살려요.
- **변신 기능은 정식 기능으로, 첫 주인공은 자체 캐릭터 둔갑이.** 변신해도 정체를 알려 주는 표시(나뭇잎)가 남아요.

## 배포

- 코드 라이선스는 MIT. 팩 그림에는 적용되지 않아요.
- 설치: Homebrew(추천), curl 한 줄, 직접 받기. Homebrew는 소스에서 빌드해서 서명 경고를 피해요.
- 버전마다 태그를 달고 Homebrew formula를 갱신해요 (`homebrew-tap` 저장소).
