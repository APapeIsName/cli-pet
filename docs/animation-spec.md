# CLIPet 애니메이션 분류 (초안)

## 원칙

1. **기능(트리거)과 그림(상태)을 분리한다.** 기능은 계속 늘어나도, 팩이 그려야 할 그림은 적게 유지한다.
2. **필수 포즈 5장만 있으면 팩이 동작한다.** 나머지 상태는 대체 규칙으로 채운다.
3. **움직임은 엔진이 맡고, 표정과 포즈는 팩이 맡는다.** 그래서 팩 제작 부담이 작다.

---

## 1. 움직임의 세 종류

| 종류 | 누가 만드나 | 예 | IP 조건 |
|---|---|---|---|
| **A. 모션** | 엔진(코드) | 둥실 숨쉬기, 통통, 점프, 흔들기, 찌그러짐, 기울기, 대롱대롱 | 그림 1장이면 됨. 단 찌그러짐·늘이기는 원본 변형으로 볼 여지가 있으니, 수정 금지 IP에서는 끈다 |
| **B. 포즈** | 팩(정지 이미지) | 기본, 웃음, 놀람, 잠, 집중 | 새 표정을 그려야 하므로 **수정·2차 창작 허용**이 필요 |
| **C. 프레임** | 팩(여러 장) | 걷기, 타이핑, 하품, 말하는 입 | B와 같은 조건이고 작업량이 크다. 전부 선택 사항 |

---

## 2. 포즈 목록 (팩이 그리는 단위)

| 등급 | 포즈 | 쓰이는 곳 |
|---|---|---|
| **필수 5** | `normal` 기본 | 평소, 착지, 알아채기 |
| | `happy` 웃음 | 클릭 반응, 완료, 인사 |
| | `focus` 집중 | 작업 중 |
| | `surprised` 놀람 | 날 봐줘(알림), 들려 있음, 깨어남 |
| | `sleep` 잠 | 잠, 졸림 |
| **권장 4** | `blink` 눈 감음 | 깜빡임 (없으면 깜빡임 생략) |
| | `dizzy` 어지러움 | 연타 (없으면 `surprised`) |
| | `think` 생각 | 생각 중 (없으면 `focus`) |
| | `sad` 시무룩 | 실패, 배고픔 (없으면 `surprised`) |
| **선택** | `tired`, `talk`, `held`, `eat`, `stretch` | 오래 작업, 말하기, 들림, 밥, 기지개 |
| **선택(프레임)** | `walk[]`, `type[]`, `yawn[]` | 돌아다니기, 타이핑, 하품 |
| **선택(소품)** | `prop:book`, `prop:pencil`, `prop:terminal`, `prop:magnifier`, `prop:globe`, `prop:friend` | 작업 종류별로 옆에 띄우는 작은 그림. 캐릭터와 무관하게 공용 소품으로 만들 수 있다 |

> 5장이면 팩이 되고, 9장이면 완성형이다.

## 3. 상태 목록 (포즈와 모션의 조합)

| 상태 | 뜻 | 포즈 | 모션 | 없으면 → |
|---|---|---|---|---|
| `idle` | 평소 | normal (+blink) | 숨쉬기 | — |
| `sleep` | 잠 | sleep | 느린 숨 + zzz | — |
| `wake` | 깨어남 | surprised → normal | 작은 점프 | idle |
| `react` | 클릭 반응 | happy | 점프 + 찌그러짐 | — |
| `dizzy` | 연타 당함 | dizzy | 비틀비틀 기울기 | react |
| `held` | 드래그 중 | held | 좌우 진자 | surprised |
| `land` | 놓았을 때 | normal | 착지 찌그러짐 | idle |
| `notice` | 마우스 올림 | normal | 살짝 기울기 | idle |
| `think` | 생각 중 | think | 느린 좌우 흔들 | work |
| `work` | 작업 중 | focus | 통통 | — |
| `work:종류` | 읽기, 수정, 실행, 검색, 웹, 도우미 | focus + 소품 | 통통 | work |
| `alert` | 날 봐줘 | surprised | 주기적 흔들기 | — |
| `done` | 끝남 | happy | 기쁜 깡총 | react |
| `error` | 실패 | sad | 축 처짐(세로로 살짝 눌림) | alert |
| `tired` | 오래 일함 | tired | 느린 통통 + 땀방울 | work |
| `talk` | 말할 때 | talk ↔ 현재 포즈 번갈아 | — | 현재 포즈 유지 |
| `walk` | 돌아다니기 | walk[] | 좌우 이동 | normal로 미끄러지듯 이동 |
| `daily:*` | 일상 행동 | eat, stretch, yawn[] | 상황별 | happy / sad / sleep |

## 4. 기능별 트리거 → 상태

### A. 같이 놀기 (마우스)
| 트리거 | 상태 | 말풍선 예 |
|---|---|---|
| 클릭 | react | 히히 / 간지러워! |
| 1.5초 안에 5번 클릭 | dizzy | 어지러워~ |
| 드래그 시작 → 놓기 | held → land | 으앗 / 휴 |
| 마우스를 올림 | notice | (없음) |
| 5분 동안 아무 일 없음 | sleep | zzz |
| 자는 중 클릭 | wake → react | 으음… 왜~ |

### B. Claude Code 따라가기 (훅)
| 트리거 | 상태 | 말풍선 예 |
|---|---|---|
| 세션 시작 | react | 안녕! |
| 프롬프트 보냄 | think | 음… 생각 중 |
| 도구 사용 (읽기, 수정, 실행, 검색, 웹, 도우미) | work:종류 | 📖 main.swift / $ npm test |
| 도구 실패 | error | 앗, 안 됐어 |
| 권한 요청 / 입력 기다림 | alert | 나 좀 봐줘! |
| 응답 끝 | done | 다 했어! |
| 한 번에 N분 이상 작업 | tired | 오래 걸리네… |

> 훅 이벤트 이름(도구 실패, 알림 종류 구분)은 구현할 때 Claude Code 문서로 다시 확인한다.

### C. 일반 CLI (`| cli-pet pipe`, 나중에 `cli-pet run`)
| 트리거 | 상태 |
|---|---|
| 출력 줄 | work + talk |
| 끝남 | done (`run`으로 종료 코드를 받게 되면 실패 시 error) |

### D. 일상 (개발 얘기가 아닌, 평범한 펫다운 부분)
| 트리거 | 상태 | 말풍선 예 |
|---|---|---|
| 그날 첫 실행 | react | 좋은 아침! |
| 점심, 저녁 시간 | daily:eat 또는 sad | 배고파… |
| 자정이 넘음 | daily:yawn → sleep | 이제 자자… |
| 1시간 넘게 쉬지 않음 | daily:stretch | 기지개 한 번 켜자 |
| 가끔 혼잣말 | talk | 오늘 날씨 어때? |
| 주말, 기념일 | react | 오늘은 쉬는 날! |

> 일상 쪽은 새 그림 없이 기본 포즈를 재사용하는 게 기본이다. 선택 포즈가 있으면 그걸 쓴다.

## 5. 동시에 일어날 때 우선순위

`held` > `alert` > `error` > `react`·`dizzy`(짧게) > `done` > `think`·`work` > `daily` > `idle` > `sleep`

- 짧은 반응(react, dizzy, land)은 위에 잠깐 겹쳐 재생하고, 끝나면 원래 상태로 돌아간다.
- 말풍선은 상태와 별개인 층이다. 상태가 바뀌어도, 우선순위가 더 높은 말이 아니면 유지한다.

## 6. IP 조사와의 연결: 팩 등급

| 팩 등급 | 필요한 그림 | 필요한 라이선스 조건 |
|---|---|---|
| **완성 팩** | 필수 + 권장 (9장 이상) | 수정·2차 창작 허용 + 재배포 허용 |
| **기본 팩** | 필수 5장 | 위와 같음 |
| **스탬프 팩** | 공식 이미지 1장 + 엔진 모션 (찌그러짐 끔) | 재배포는 되지만 수정은 금지인 경우. 표정 변화가 없어서 체험이 약하다. 비추천 |
| **사용자 팩** | 앱은 형식만 제공하고 그림은 사용자가 직접 넣음 | 앱에 포함하지 않음. 사용자가 넣은 그림의 권리 문제는 앱이 판단할 수 없으므로 안내 문구 필요 |

IP마다 확인할 것은 세 가지다: **수정 허용?** / **앱에 넣어 재배포 허용?** / **표기 의무(출처, 라이선스, 공유 조건)?**

## 7. 팩 형식 (초안)

```
packs/gopher/
  pack.json
  normal.png  happy.png  focus.png  surprised.png  sleep.png   ← 필수
  blink.png   dizzy.png  think.png  sad.png                     ← 권장
```

```json
{
  "id": "gopher",
  "name": "Go Gopher",
  "credit": "Renée French",
  "license": "CC BY 4.0",
  "poses": { "normal": "normal.png", "happy": "happy.png" },
  "frames": { "walk": ["walk1.png", "walk2.png"] },
  "motion": { "squash": true }
}
```

- `credit`과 `license`는 앱의 "정보" 화면과 팩 선택 화면에 그대로 표시한다.
- `motion.squash: false` 이면 찌그러짐·늘이기를 끈다 (수정 금지 IP 대비).
